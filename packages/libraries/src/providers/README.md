## Architecture & Provider Interface

Every provider implements the abstract [`BaseSocialProvider`](../base/base.provider.ts) and supplies:
- **`metadata`**: Platform ID, name, capabilities, character/media limits, and default OAuth scopes.
- **`validatePost(payload)`**: Runs validation logic against the platform's limits and format rules.
- **`getAuthUrl(options)`**: Generates the OAuth2 / authorization redirect URL.
- **`exchangeCode(options)`**: Exchanges authorization code / credentials for hardware-encrypted access & refresh tokens.
- **`refreshToken(refreshToken, currentCredentials)`**: Automatically rotates expired tokens.
- **`verifyCredentials(credentials)`**: Fetches fresh profile details and tests token health.
- **`publishPost(payload, credentials)`**: Dispatches the formatted payload to the platform's remote endpoint.
